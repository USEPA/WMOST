The files included in the release of WMOST v3 include the following:

1. WMOSTv3_02-01-18b.zip contains:
   WMOSTv3_020118b.xlsm ? Empty copy of WMOST version 3 for new case study data entry
 
2. Hydroprocessor executable files for formatting HSPF and SWAT model outputs for use in WMOST
   a. Hydroprocessorx86 (32-bit version for processing single basin)
   b. Hydroprocessor64bit (64-bit version for processing single basin)
   c. Batch Hydroprocessorx86 (32-bit version for processing multiple basins within a watershed model)
   d. Batch Hydroprocessor64bit (64-bit version for processing multiple basins within a watershed model)

3.  Watershed maps - zipped file of pdf maps showing watershed codes for individual basins within preprocessed watershed models available for automatic
	import to WMOSTv3

To install WMOSTv3, the user will need to download and unzip WMOSTv3_02-01-18b.zip.
